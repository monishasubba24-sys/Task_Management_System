# Task & Project Management System

## Project Domain
Productivity & Team Collaboration

## Project Description
TaskFlow is a web-based Task and Project Management System that helps teams organize projects, assign tasks, monitor progress, and manage deadlines through a centralized platform.

The system allows administrators and project managers to create projects, manage team members, assign tasks, and track project completion. Team members can view their assigned tasks and update their task status.
