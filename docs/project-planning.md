# PROJECT PLANNING DOCUMENT

## 1. Project Selection

**Project Name:** Task & Project Management System (TaskFlow)

**Project Template ID:** T12

**Domain:** Productivity & Team Collaboration

**Technology Stack:** MongoDB, Express.js, React.js and Node.js (MERN Stack)

## 2. Problem Statement

Many student teams and small organizations face difficulties in managing projects, assigning tasks and monitoring work progress. They often use notebooks, spreadsheets and messaging applications to organize their work.

These methods can cause missed deadlines, poor communication, confusion about responsibilities and difficulty tracking project completion.

The problem affects administrators, project managers and team members who need to work together.

Therefore, a centralized Task & Project Management System is needed to organize projects, assign responsibilities, monitor deadlines and improve team productivity.

## 3. Project Objectives

The main objective is to develop a web-based Task & Project Management System using the MERN Stack.

Specific objectives:

1. To provide secure user registration and login.
2. To allow project managers to create, update and delete projects.
3. To assign team members to different projects.
4. To create and assign tasks to team members.
5. To manage task priorities and due dates.
6. To track task status and project completion.
7. To provide a dashboard for monitoring project progress.
8. To generate project and task reports.

## 4. Stakeholders

### Administrator
- Manages users.
- Manages projects.
- Controls system settings.
- Views reports.

### Project Manager
- Creates projects.
- Assigns tasks.
- Manages team members.
- Monitors project progress.

### Team Member
- Views assigned tasks.
- Updates task status.
- Manages personal profile.

## 5. Project Scope

### Included Features
1. User registration and login.
2. User authentication and role-based authorization.
3. Project creation, updating and deletion.
4. Project details and status management.
5. Adding and managing team members.
6. Creating and assigning tasks.
7. Task priority and due-date management.
8. Updating task status.
9. Project progress tracking.
10. Dashboard and productivity reports.

### Excluded Features
1. Video conferencing integration.
2. Real-time chat system.
3. AI-based task recommendations.
4. Calendar synchronization.
5. Email notification services.
6. Mobile application.

## 6. Conclusion

TaskFlow provides a centralized platform for managing projects and tasks. It helps teams organize their work, manage responsibilities, monitor deadlines and improve productivity.
