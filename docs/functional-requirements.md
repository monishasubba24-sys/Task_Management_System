# FUNCTIONAL REQUIREMENTS

Functional requirements describe what the TaskFlow system should do.

| ID | Requirement | Description |
|---|---|---|
| FR01 | User Registration | Users can create accounts. |
| FR02 | User Login | Users can securely log in. |
| FR03 | Role Management | System supports different user roles. |
| FR04 | User Profile | Users can manage their profiles. |
| FR05 | Create Project | Project managers can create projects. |
| FR06 | Update Project | Project managers can modify project details. |
| FR07 | Delete Project | Authorized users can delete projects. |
| FR08 | View Project | Users can view project information. |
| FR09 | Add Team Members | Managers can add members to projects. |
| FR10 | Assign Members | Members can be assigned to projects. |
| FR11 | Create Tasks | Project managers can create tasks. |
| FR12 | Assign Tasks | Tasks can be assigned to team members. |
| FR13 | Update Tasks | Users can update task details according to their permissions. |
| FR14 | Delete Tasks | Authorized users can delete tasks. |
| FR15 | Set Priority | Tasks can have different priority levels. |
| FR16 | Set Due Date | Tasks can have deadlines. |
| FR17 | Update Task Status | Members can update task progress. |
| FR18 | Track Progress | System can track project completion. |
| FR19 | Dashboard | Users can view project information. |
| FR20 | Generate Reports | System can generate project and task reports. |

## Conclusion

These functional requirements define the main features that TaskFlow must provide to support project and task management.
